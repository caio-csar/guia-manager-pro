# Guia Manager Pro

Versão experimental do Guia Manager, criada sem alterar o projeto estável `guia-manager-telas`.

## Objetivo

Oferecer uma interface mais prática para o suporte localizar telas, flags, funções e recursos do sistema Manager.

## Recursos

- Busca por link direto com `?q=termo`.
- Modo suporte com sinônimos de problemas reais do atendimento.
- Favoritos locais salvos no navegador.
- Botão para copiar resultado.
- Botão para copiar link direto da consulta.
- Tema claro/escuro.
- Base carregada a partir do guia estável.
- `noindex` e `robots.txt` para reduzir indexação.
